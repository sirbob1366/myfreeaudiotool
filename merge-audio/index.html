Join multiple audio files into a single track. Drag to set the order, then export as WAV or MP3.

    How to merge audio files online

    1. Add your files — drop two or more audio files (they can be different formats; we'll handle mixing sample rates).
    2. Set the order — drag the rows, or use the arrows on mobile. Top plays first.
    3. Merge — download the joined result as lossless WAV or compact MP3.

    Mix any formats together

    You can merge an MP3 with a WAV and an M4A in one go. Each file is decoded with the Web Audio API and automatically resampled to a common sample rate and channel layout before the tracks are joined back-to-back. Everything happens locally — perfect for combining voice memos, stitching podcast segments, or joining song parts without installing software.
