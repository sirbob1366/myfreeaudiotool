Audio Speed Changer

Slow down a track to learn it, or speed up a lecture to save time — anywhere from 0.25× to 4×, with instant preview.

🔒 Processed in your browser — never uploaded

Drop your audio file here

or click to browse — MP3, WAV, M4A, OGG, FLAC and more

Note: the live preview keeps the original pitch (your browser's time-stretching). The exported file uses classic varispeed — pitch shifts with speed, like a vinyl record.

Change audio speed without installing anything

This tool decodes your file with the Web Audio API and re-renders it at the speed you choose using an OfflineAudioContext — all on your device. Slowing to 0.5× doubles the duration; speeding to 2× halves it.

Pitch preservation: preview vs. export

While previewing, your browser applies built-in time-stretching, so voices stay at their natural pitch. The downloadable file is rendered with varispeed resampling, which shifts pitch along with speed (slower = deeper, faster = higher) — the classic turntable effect. For most uses — practicing music slowly, skimming lectures, creating slowed + reverb style edits — this is exactly what you want.

Popular uses

  • Slow down guitar solos or piano pieces to practice along.
  • Speed up lectures, meetings and voice memos to 1.5–2×.
  • Create slowed-down or sped-up (nightcore-style) versions of songs.
