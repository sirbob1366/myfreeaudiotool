Reporting a problem

If a tool isn't working for you, including the following details helps us fix it quickly:

  • Which tool and what you were trying to do
  • Your browser and device (e.g. "Chrome on Windows 11", "Safari on iPhone 15")
  • The file format and rough size (we never need the file itself — and we couldn't receive it anyway)
  • Any error message shown on the page

A note on privacy

Since all processing happens in your browser, we can't recover, inspect or debug your specific files — they never reach us. That's by design.
